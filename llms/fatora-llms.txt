# Fatora

> Fatora is a Qatar-based online invoicing and payment platform (operated by MaktApp) serving 120,000+ merchants across Arabic-speaking / MENA markets. It offers invoicing, an online store, POS/cashier, payment links, and a card payment gateway, plus a REST API for checkout, tokenization, refunds, verification, and CRUD over invoices, clients, and products.

## APIs

- [Fatora REST API](https://fatora.io/api/): Hosted-checkout payments, tokenization, refunds, verification, and invoice/client/product management. Base URL https://api.fatora.io/v1.
- [API Reference (Stoplight)](https://fatora-api.stoplight.io/docs/API-reference/ZG9jOjE-fatora-rest-api): Full REST reference.

## Authentication

- [Authentication](https://fatora.io/api/authentication.php): api_key header for payment endpoints; Bearer JWT (via https://api.fatora.io/v1/Authorization/Authorize) for invoice/client/product endpoints.
